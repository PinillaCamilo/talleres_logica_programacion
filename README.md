## Descripción

Este repositorio contiene la solución del taller de Lógica de Programación: 15 ejercicios clasificados en tres niveles de dificultad (básico, intermedio y avanzado). Cada ejercicio incluye su enunciado, un breve análisis, el pseudocódigo (con declaración de variables) y el diagrama de flujo correspondiente.
